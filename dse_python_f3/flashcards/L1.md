## L1-C01 · print 让电脑说话

### 正面
- **问题**：Python 里让电脑"喊话"用哪个函数？
- **英文术语**：print = 打印/输出
- **填空**：`______("Hello")` 输出 Hello 到屏幕

### 反面
- **答案**：`print()` 函数（动词，打印/输出）
- **口诀**：print = 大喇叭，对着电脑喊一句话
- **完整代码**：
  ```python
  print("Hello")          # 输出 Hello
  print(2 + 3)             # 输出 5
  print("Hello", "World")  # 输出 Hello World（逗号自动空格）
  ```
- **易错点**：
  - ⭐ 漏掉括号 `print("Hello")` → SyntaxError
  - ⭐ 漏掉引号 `print(Hello)` → NameError（Python 以为 Hello 是变量）
- **相关**：与 L1-C02 变量、L1-C03 input 组合用

## L1-C02 · 变量 = 装数据的碗

### 正面
- **问题**：Python 里 `age = 15` 是什么意思？
- **英文术语**：Variable = 变量
- **填空**：变量就像贴了标签的`______`，碗里可以换东西

### 反面
- **答案**：把数字 15 放进名字叫 age 的碗里
- **口诀**：变量 = 贴标签的碗（标签 = 变量名，碗里的东西 = 值）
- **完整代码**：
  ```python
  age = 15
  print(age)       # 输出 15
  age = 18         # 把碗里的东西换成 18
  print(age)       # 输出 18（覆盖原值，不是叠加）
  ```
- **易错点**：
  - ⭐ 数字开头非法：`2name = 5` → SyntaxError
  - ⭐ 关键字不能当变量名：`class = 5` → SyntaxError
  - ⭐ 大小写敏感：`Age` 和 `age` 是两个不同的碗
- **合法变量名举例**：my_age / _score / userName / age2

## L1-C03 · input 让电脑听键盘

### 正面
- **问题**：`input()` 函数永远返回什么类型？
- **英文术语**：input = 输入
- **填空**：`name = input("名字?")` —— name 永远是 `______` 类型

### 反面
- **答案**：`str`（字符串）
- **口诀**：input 永远给你"文字"，想算数要 `int(input())`
- **完整代码**：
  ```python
  a = input("First: ")   # 用户输入 5
  b = input("Second: ")  # 用户输入 3
  print(a + b)            # 输出 53（不是 8！）
  ```
- **易错点**：
  - ⭐ 永远返回字符串：`"5" + "3" = "53"`（字符串拼接，不是数学加）
  - ⭐ 想算数必须包 int：`int(input(...))`
- **相关**：L2 类型转换章节详细讲怎么把字符串转数字

## L1-C04 · IPO 模型（程序的骨架）

### 正面
- **问题**：IPO 三个字母分别代表什么？
- **英文术语**：Input-Process-Output
- **填空**：写程序的三步曲：I（输入）→ P（处理）→ O（`______`）

### 反面
- **答案**：Input（输入）/ Process（处理）/ Output（输出）
- **口诀**：IPO = 餐厅点菜（听单 → 厨房做 → 上菜）
- **完整代码**（IPO 完整例子）：
  ```python
  # I - Input（输入）
  name = input("你的名字: ")
  
  # P - Process（处理）
  greeting = "Hello, " + name + "!"
  
  # O - Output（输出）
  print(greeting)
  ```
- **易错点**：
  - ⭐ 忘了写 O：写了 input 和 print，但中间没处理
  - ⭐ IPO 顺序：先 I 再 P 最后 O，不要颠倒
- **相关**：每道编程题先用 IPO 分析，再写代码
