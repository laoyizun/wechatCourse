## 卡片格式说明

每张卡的格式：

```
## L1-C01 · 概念名
### 正面
（核心问题、英文术语、填空式代码）
### 反面
（一句话回答、口诀、完整代码、易错点）
```

**C01** 表示该课第 1 个概念（Card 01）。
