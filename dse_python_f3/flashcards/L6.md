## L6-C01 · 列表创建与索引

### 正面
- **问题**：`fruits = ["apple", "banana"]` 怎么访问第一个和最后一个元素？
- **英文术语**：list / index
- **填空**：
  - `fruits[0]` → `______`（第一个）
  - `fruits[-1]` → `______`（最后一个）

### 反面
- **答案**：
  - `fruits[0]` → `"apple"`（第一个元素）
  - `fruits[-1]` → `"banana"`（最后一个元素）
- **口诀**：列表 = 一列储物柜（每个柜子有编号）
- **完整代码**：
  ```python
  fruits = ["apple", "banana", "cherry"]
  print(fruits[0])    # apple（第 1 个）
  print(fruits[1])    # banana（第 2 个）
  print(fruits[-1])   # cherry（最后 1 个）
  print(fruits[-2])   # banana（倒数第 2 个）
  ```
- **关键规则**：
  - ⭐ 索引从 0 开始（不是 1）
  - ⭐ 负索引 -1 = 最后，-2 = 倒数第二
  - ⭐ 越界报错：`fruits[10]` → IndexError

## L6-C02 · 切片 [start:end:step]

### 正面
- **问题**：`lst = [0, 1, 2, 3, 4, 5]`，`lst[1:4]` 是哪些元素？
- **英文术语**：slicing
- **填空**：切片 `[start:end:step]` 左`______`右开（end 不算）

### 反面
- **答案**：`lst[1:4]` → `[1, 2, 3]`（不含 4）
- **完整切片语法**：
  | 切片 | 结果 | 说明 |
  | --- | --- | --- |
  | `lst[1:4]` | `[1, 2, 3]` | 1 到 3 |
  | `lst[:3]` | `[0, 1, 2]` | 前 3 个 |
  | `lst[3:]` | `[3, 4, 5]` | 第 4 个到末尾 |
  | `lst[::-1]` | `[5, 4, 3, 2, 1, 0]` | 反转 |
  | `lst[::2]` | `[0, 2, 4]` | 步长 2 |
- **口诀**：切片 = 取一段柜子（左闭右开）
- **实战**：
  - 字符串反转：`s[::-1]`
  - 取前 3 名：`scores[:3]`

## L6-C03 · 列表增删改

### 正面
- **问题**：列表有哪些增删改方法？
- **英文术语**：list methods
- **填空**：
  - `lst.append(x)` 把 x 加到`______`
  - `lst.pop()` 删除`______`一个
  - `lst.insert(i, x)` 在 i 位置`______`x

### 反面
- **答案**：
  | 方法 | 作用 | 例子 |
  | --- | --- | --- |
  | `append(x)` | 末尾加 x | `lst.append(5)` |
  | `insert(i, x)` | 在位置 i 插入 x | `lst.insert(0, 5)` |
  | `pop()` | 删最后一个 | `lst.pop()` |
  | `pop(i)` | 删位置 i | `lst.pop(0)` |
  | `del lst[i]` | 删位置 i | `del lst[0]` |
  | `remove(x)` | 删第一个 x | `lst.remove(5)` |
- **完整代码**：
  ```python
  lst = [1, 2, 3]
  lst.append(4)        # [1, 2, 3, 4]
  lst.insert(0, 0)     # [0, 1, 2, 3, 4]
  lst.pop()            # [0, 1, 2, 3]
  lst.remove(1)        # [0, 2, 3]
  ```
- **易错点**：
  - ⭐ `append` 一次加一个；想加多个用 `extend`

## L6-C04 · 列表统计排序

### 正面
- **问题**：列表有哪些内置函数和方法？
- **英文术语**：built-in functions
- **填空**：
  - `len(lst)` → `______`（元素个数）
  - `max(lst)` → `______`（最大值）
  - `lst.sort()` → 列表`______`排序（从小到大）

### 反面
- **答案**：
  | 函数 / 方法 | 作用 |
  | --- | --- |
  | `len(lst)` | 元素个数 |
  | `max(lst)` | 最大值 |
  | `min(lst)` | 最小值 |
  | `sum(lst)` | 总和 |
  | `lst.sort()` | 升序排序（修改原列表）|
  | `lst.sort(reverse=True)` | 降序 |
  | `lst.reverse()` | 反转 |
  | `x in lst` | 检查 x 是否在列表里 |
- **完整代码**：
  ```python
  scores = [85, 92, 78, 95, 88]
  print(len(scores))       # 5
  print(max(scores))       # 95
  print(sum(scores))       # 438
  print(85 in scores)      # True
  scores.sort()             # [78, 85, 88, 92, 95]
  scores.sort(reverse=True) # [95, 92, 88, 85, 78]
  ```
- **易错点**：
  - ⭐ `sort()` 修改原列表；`sorted()` 返回新列表
  - ⭐ `sum` 不能用于字符串列表
