## L4-C01 · while 条件循环

### 正面
- **问题**：`while` 循环什么时候停下？
- **英文术语**：while loop
- **填空**：
  ```python
  i = 1
  while i <= 5:
      print(i)
      i = i + 1   # 重要！计数器
  ```

### 反面
- **答案**：条件为假时停下（`i <= 5` 为 False 时停）
- **口诀**：while = 旋转门（条件真就一直转）
- **完整代码**：
  ```python
  i = 1
  while i <= 5:
      print(i)
      i = i + 1
  # 输出：1 2 3 4 5
  ```
- **易错点**：
  - ⭐ **忘写计数器** `i = i + 1` → 死循环
  - ⭐ 条件永远真 → 死循环
  - ⭐ 缩进错 → 循环体错位

## L4-C02 · break 跳出循环

### 正面
- **问题**：`break` 在循环里做什么？
- **英文术语**：break = 跳出
- **填空**：
  ```python
  while True:
      pwd = input("密码?")
      if pwd == "123":
          ______
      print("密码错")
  ```

### 反面
- **答案**：立刻跳出整个循环（不管条件真假）
- **口诀**：break = 紧急出口（拉一下就开门）
- **完整代码**：
  ```python
  while True:
      pwd = input("密码?")
      if pwd == "123":
          print("欢迎")
          break          # 跳出
      print("密码错")
  print("程序结束")
  ```
- **易错点**：
  - ⭐ 漏写 break → 验证成功后还会继续循环
  - ⭐ break 只跳出一层（嵌套循环里）

## L4-C03 · continue 跳过本轮

### 正面
- **问题**：`continue` 在循环里做什么？和 `break` 有什么区别？
- **英文术语**：continue = 继续
- **填空**：
  ```python
  for i in range(1, 6):
      if i == 3:
          ______
      print(i)
  ```

### 反面
- **答案**：`continue` 跳过本轮剩下代码，进入下一轮（不跳出循环）
- **对比**：
  | 关键字 | 作用 |
  | --- | --- |
  | `break` | 跳出整个循环 |
  | `continue` | 跳过本轮，进入下一轮 |
- **完整代码**：
  ```python
  for i in range(1, 6):
      if i == 3:
          continue       # 跳过本轮
      print(i)
  # 输出：1 2 4 5（没 3）
  ```
- **实战**：讨价还价（`>= 100` 才 break，否则 continue 下一轮）

## L4-C04 · 防死循环

### 正面
- **问题**：下面代码有什么问题？
  ```python
  i = 1
  while i <= 5:
      print(i)
  ```
- **英文术语**：infinite loop / 死循环
- **填空**：`while` 循环必须有 3 件套：起点 / `______` / 更新

### 反面
- **答案**：死循环（条件永远为真，因为 `i` 不变）
- **口诀**：while 三件套 — 计数器起点 / 条件 / `i = i + 1` 更新
- **正确代码**：
  ```python
  i = 1                  # 1. 起点
  while i <= 5:          # 2. 条件
      print(i)
      i = i + 1          # 3. 更新
  ```
- **死循环 3 种情况**：
  - ⭐ 忘写计数器
  - ⭐ 计数器写错位置（写错循环体里）
  - � 条件永远真（`while True` 没 break）
- **急救**：按 Ctrl+C 强制停止
