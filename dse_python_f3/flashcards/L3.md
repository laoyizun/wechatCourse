## L3-C01 · 比较运算符 6 个

### 正面
- **问题**：Python 里 6 个比较运算符分别是什么？
- **英文术语**：Comparison Operators
- **填空**：
  - `5 == 5` → `______`
  - `5 != 3` → `______`
  - `5 > 3` → `______`

### 反面
- **答案**：
  | 运算符 | 含义 | 例子 |
  | --- | --- | --- |
  | `==` | 等于 | `5 == 5 → True` |
  | `!=` | 不等于 | `5 != 3 → True` |
  | `>` | 大于 | `5 > 3 → True` |
  | `<` | 小于 | `5 < 3 → False` |
  | `>=` | ≥ | `5 >= 5 → True` |
  | `<=` | ≤ | `5 <= 3 → False` |
- **口诀**：比较运算 = 体重秤，判断两个值的关系
- **完整代码**：
  ```python
  age = 18
  print(age == 18)   # True
  print(age >= 18)   # True
  print(age < 18)    # False
  ```
- **易错点**：
  - ⭐ **`=` vs `==`**：`=` 是赋值（把东西放进碗），`==` 是比较（问碗里是不是）
  - ⭐ 单等号写比较：`if age = 18` → SyntaxError
- **口诀**：单 `=` 放进碗里，双 `==` 看碗里是不是

## L3-C02 · if-else 二选一

### 正面
- **问题**：`if-else` 的基本语法是什么？哪个符号不能漏？
- **英文术语**：Conditional Statement
- **填空**：
  ```python
  if 条件:
      ______(条件为真)
  ______(冒号必须有):
      print("条件为假")
  ```

### 反面
- **答案**：`if 条件:` 后必须写 **冒号** 和 **缩进 4 空格**
- **口诀**：if-else = 闸道，要么走这边要么走那边
- **完整代码**：
  ```python
  age = int(input("年龄?"))
  if age >= 18:
      print("成年")
  else:
      print("未成年")
  ```
- **易错点**：
  - ⭐ **冒号漏掉**：`if age >= 18` → SyntaxError
  - ⭐ **缩进错**：`if` 后没缩进 → IndentationError
  - ⭐ **else 写错位置**：`else` 必须和 `if` 顶格对齐
- **实战**：先看条件为真还是假 → 决定走 if 还是 else

## L3-C03 · 逻辑运算 and / or / not

### 正面
- **问题**：3 个逻辑运算符分别是什么？
- **英文术语**：Logical Operators
- **填空**：
  - `True and False` → `______`（两边都真才真）
  - `True or False` → `______`（一边真就真）
  - `not True` → `______`（反过来）

### 反面
- **答案**：
  | 运算符 | 含义 | 真值表 |
  | --- | --- | --- |
  | `and` | 两边都真才真 | T and T → T，其他都 F |
  | `or` | 一边真就真 | F or F → F，其他都 T |
  | `not` | 反过来 | not T → F，not F → T |
- **口诀**：
  - `and` = "都要带齐才能进门"
  - `or` = "任一带一样就能进门"
  - `not` = "今天不是周末"
- **完整代码**：
  ```python
  age = int(input("年龄?"))
  has_ticket = input("有票吗(yes/no)?")
  if age >= 18 and has_ticket == "yes":
      print("欢迎进入")
  else:
      print("不能进")
  ```
- **实战**：判断能否进演唱会（年龄 + 票）= 经典 and 用例

## L3-C04 · if-elif-else 多分支

### 正面
- **问题**：成绩分级用 `if-elif-else`，从 90 / 80 / 70 / 60 / < 60 分别输出什么？
- **英文术语**：Multi-way Decisions
- **填空**：
  ```python
  if score >= 90:
      print("A")
  elif score >= 80:
      print("B")
  ______(其他):
      print("F")
  ```

### 反面
- **答案**：
  ```python
  score = 85
  if score >= 90:
      print("A · 优秀")
  elif score >= 80:
      print("B · 良好")
  elif score >= 70:
      print("C · 中等")
  elif score >= 60:
      print("D · 及格")
  else:
      print("F · 不及格")
  ```
- **口诀**：elif = "else if" 的缩写，可以有任意多个
- **关键规则**：
  - ⭐ Python 从上到下检查，**遇到第一个 True 就停**
  - � `else` 是"全部都假"才执行，可选
- **易错点**：
  - ⭐ 顺序写错：先写 `>= 60` 再写 `>= 90` → 永远命中第一个

## L3-S01 · 杀手锏：边界测试（49/50/51 三角验证）

### 正面
- **问题**：测试 `if score >= 50` 程序，至少要测哪 3 个值？
- **英文术语**：Boundary Testing
- **填空**：临界点测试要测`______`、`______`、`______`（刚好不达 / 刚好达到 / 刚好超过）

### 反面
- **答案**：测 `49`（刚好不达）/ `50`（刚好达到）/ `51`（刚好超过）
- **为什么是 3 个**：49 看 else，50 看 if 用 `>=` 还是 `>`，51 看 if 主分支
- **完整测试矩阵**：
  | 输入 | 预期 | 目的 |
  | --- | --- | --- |
  | 49 | 不及格 | 验证 else 分支 |
  | **50** | **及格** | **验证用 `>=` 不是 `>`** |
  | 51 | 及格 | 验证 if 分支 |
- **易错点**：
  - ⭐ 只测 49 和 50 测不出错：必须用 51
  - ⭐ 漏测边界：写 `if score == 50` 这种"刚好等于"逻辑会漏掉其他分数
- **实战**：DSE 真题 Q3 三角形分类必用边界

## L3-S02 · 杀手锏：Better If 早返错误

### 正面
- **问题**："Better If" 的核心思想是什么？
- **英文术语**：Early Return / Flat Code
- **填空**：先排除`______`情况，主体逻辑更扁平清晰

### 反面
- **答案**：**先返错**（错误条件提前 return / 处理），主体逻辑更扁
- **为什么 Better**：
  - 错误处理不污染主逻辑
  - 缩进层数少，一眼看懂
  - 嵌套 if 不需要，用 `or` 一句话搞定
- **对比代码**：

  ```python
  # Version 1 — 嵌套很深，难读
  if score >= 0 and score <= 100:
      if score >= 50:
          print("及格")
      else:
          print("不及格")
  else:
      print("无效")

  # Version 2 — Better If（推荐）
  if score < 0 or score > 100:
      print("无效")
  elif score >= 50:
      print("及格")
  else:
      print("不及格")
  ```

- **实战**：所有"先验证输入合法性"的题都用 Better If
