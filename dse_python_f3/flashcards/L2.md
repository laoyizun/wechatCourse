## L2-C01 · 四种数据类型

### 正面
- **问题**：Python 里 4 种基础数据类型分别用什么关键字？
- **英文术语**：int / float / str / bool
- **填空**：
  - `15` 是 `______`（整数）
  - `3.14` 是 `______`（小数）
  - `"Hello"` 是 `______`（文字）
  - `True` 是 `______`（开关）

### 反面
- **答案**：`int` / `float` / `str` / `bool`
- **口诀**：碗装四种不同食材（米 = int，水 = float，文字 = str，开关 = bool）
- **完整代码**：
  ```python
  age = 15           # int
  height = 1.75      # float
  name = "Peter"     # str
  is_adult = True    # bool
  ```
- **易错点**：
  - ⭐ 整数和小数要分清：`5` 是 int，`5.0` 是 float
  - ⭐ 引号决定类型：`"5"` 是 str，`5` 是 int（完全不同）
- **相关**：与 L2-C02 类型转换、L3 比较运算（`==`）组合用

## L2-C02 · 类型转换函数

### 正面
- **问题**：`int(3.6)` 等于多少？
- **英文术语**：Type Conversion
- **填空**：把字符串变整数用 `______("3")`，把整数变字符串用 `______(5)`

### 反面
- **答案**：`3`（不是 4 ——int() 是截断小数，不是四舍五入）
- **口诀**：转换函数 = 改装师傅（str/int/float/bool 四件套）
- **完整代码**：
  ```python
  int("3")        # → 3（字符串转整数）
  float("3.14")   # → 3.14（字符串转小数）
  str(15)         # → "15"（整数转字符串）
  bool(1)         # → True（任何非零数都转 True）
  bool(0)         # → False
  int(3.6)        # → 3（截断，不是 4！）
  ```
- **易错点**：
  - ⭐ `int(3.6)` 是 3 不是 4（截断，不是四舍五入）
  - ⭐ `int("3.6")` 会报错（要先 `float("3.6")` 再 `int`）
- **实战**：input 后想算数必须包 int：`int(input(...))`

## L2-C03 · f-string 把变量塞进字符串

### 正面
- **问题**：`print(f"Hello, {name}")` 里的 `f` 和 `{}` 是什么意思？
- **英文术语**：formatted string
- **填空**：f-string 的 `{}` 是`______`，里面放变量或表达式

### 反面
- **答案**：`f` = format（格式化），`{}` = 占位空位
- **口诀**：f-string = 模板填空，`{}` 是空格，填入变量值
- **完整代码**：
  ```python
  name = "Peter"
  age = 15
  print(f"Hello, {name}!")           # Hello, Peter!
  print(f"You are {age} years old")   # You are 15 years old
  print(f"Next year: {age + 1}")      # Next year: 16
  ```
- **与 `+` 拼接对比**：
  ```python
  # f-string 版（推荐）
  print(f"You are {age}")
  # + 拼接版（啰嗦）
  print("You are " + str(age))
  ```
- **易错点**：
  - ⭐ 忘写 `f`：`"Hello, {name}"` → 字面输出，不会填值
  - ⭐ {} 里放 str 需要引号：`f"{'Peter'}"`，否则变成变量名
- **相关**：L3 用 f-string 输出条件判断结果

## L2-C04 · 算术运算符 6 件套

### 正面
- **问题**：Python 里 6 个算术运算符分别是什么？
- **英文术语**：Arithmetic Operators
- **填空**：
  - `10 / 3` → `______`（除法，永远返回小数）
  - `10 % 3` → `______`（取余，分糖果后剩下的零头）
  - `2 ** 3` → `______`（幂，2 的 3 次方）

### 反面
- **答案**：
  | 运算符 | 含义 | 例子 |
  | --- | --- | --- |
  | `+` | 加 | `5 + 3 = 8` |
  | `-` | 减 | `5 - 3 = 2` |
  | `*` | 乘 | `5 * 3 = 15` |
  | `/` | 除 | `10 / 4 = 2.5`（永远 float） |
  | `%` | 取余 | `10 % 3 = 1` |
  | `**` | 幂 | `2 ** 3 = 8` |
- **口诀**：取余 = 分糖果后剩下的；幂 = 自我复制 N 次
- **完整代码**：
  ```python
  print(10 / 4)    # 2.5（注意！）
  print(10 // 4)   # 2（// 是整除）
  print(10 % 3)    # 1
  print(2 ** 10)   # 1024
  ```
- **易错点**：
  - ⭐ `/` 永远返回 float：`5 / 2 = 2.5`，不是 2
  - ⭐ `**` 不是 `^`：`2 ^ 3` 是位运算 XOR，不是 8

## L2-C05 · L1 三个 Bug 怎么修

### 正面
- **问题**：下面代码会怎样？怎么修？
  ```python
  birth = input("出生年份: ")
  age = 2025 - birth
  print(age)
  ```
- **英文术语**：Bug Fix / Type Error
- **填空**：`input()` 永远返回`______`，想算数必须用 `______` 转换

### 反面
- **答案**：
  - **错误**：`TypeError: unsupported operand type(s) for -: 'int' and 'str'`
  - **修复**：把 `birth` 用 `int()` 转成整数
- **完整修复代码**：
  ```python
  birth = input("出生年份: ")
  age = 2025 - int(birth)  # ✅ 用 int() 包裹
  print(f"You are {age} years old")
  ```
- **常见 Bug 集锦**：
  | Bug | 错误 | 修复 |
  | --- | --- | --- |
  | input 没转 int | TypeError | 用 `int(input())` |
  | print 漏引号 | NameError | 加引号 `print("Hello")` |
  | 字符串拼接 int | TypeError | 用 f-string 或 `str()` |
  | 缩进错 | SyntaxError | 检查冒号后的 4 空格 |
- **相关**：L0-C08/09/10 是这3 个 Bug 的专项练习
