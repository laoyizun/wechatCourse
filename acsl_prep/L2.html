🪆 Analogy 1 · 俄罗斯套娃

递归就像俄罗斯套娃
Matryoshka dolls

打开一个 → 里面还有一个更小的 → ... → 最小的打不开（终止）
Open one, find a smaller one inside, until the smallest can't open

套娃的结构

open_doll(doll):
    if doll == smallest:    ← ① 终止条件
        return doll          （最小的打不开）
    inner = open_doll(doll.inner)  ← ② 自己调自己 + 规模缩小
    return inner

关键点对应

  • ① 终止条件 = 最小的套娃打不开
  • ② 自己调自己 = 每打开一个套娃，里面还有一个
  • ③ 规模缩小 = 里层套娃比外层小
🗼 Analogy 2 · 汉诺塔 Tower of Hanoi

汉诺塔 · 经典递归
Hanoi(n) = 2 × Hanoi(n−1) + 1

传说级问题：64 个盘子从 A 移到 C，最少多少步？
Move 64 disks from A to C — how many moves?

汉诺塔递归定义

把 n 个盘子从 A 移到 C（用 B 做中转）：

hanoi(n) =
   2 × hanoi(n-1) + 1      if n > 1
   1                          if n = 1   ← 终止条件
🎯 关键直觉

要移 n 个盘子：
① 先把上面 n-1 个挪到 B（hanoi(n-1) 步）
② 把最大的挪到 C（1 步）
③ 再把 n-1 个从 B 挪到 C（hanoi(n-1) 步）

⚡ 直观感受

hanoi(10) ≈ 1023 步；hanoi(64) ≈ 1.8 × 10¹⁹ 步（宇宙年龄都不够跑完）。

🔑 Three Elements

递归三要素
The 3 Elements of Recursion

所有递归都包含这 3 个要素 · 缺一不可

① 终止条件 Base case

递归到什么时候停下来 · 没有终止条件 = 死循环
When does recursion stop? Without it → infinite loop!

if n <= 1:           ← 终止条件
    return 1

② 自己调自己 Self-call

函数定义里调用自己 · "递归"二字的本质
Function calls itself — that's what makes it recursive

return f(n-1)        ← 关键：调自己

③ 规模缩小 Shrinking

参数越来越接近终止条件 · 否则永远停不下来
Argument must approach the base case

f(n-1), f(n-2), f(n/2)...  ← 距离 base 越来越近
🧮 Example 1 · Factorial

第一个递归 · 阶乘
fact(n) = n × fact(n−1)

5! = 5 × 4 × 3 × 2 × 1 = 120
5! = 120 — the classic first recursion example

阶乘递归定义

fact(n) =
   n × fact(n-1)    if n > 1     ← 自己调自己 + 规模缩小
   1                  if n <= 1   ← 终止条件

手算 fact(5) · 完整过程

fact(5)
= 5 × fact(4)
= 5 × 4 × fact(3)
= 5 × 4 × 3 × fact(2)
= 5 × 4 × 3 × 2 × fact(1)
= 5 × 4 × 3 × 2 × 1   ← base case 命中
= 120
🎯 三要素检查
  1. 终止条件：fact(1) = 1 ✅
  2. 自己调自己：fact(n) 里有 fact(n-1) ✅
  3. 规模缩小：参数从 n 变成 n-1，趋近 1 ✅
🌳 Call Tree · 调用树

画调用树 · 手算递归的核心技能
How to draw a call tree

所有递归题的第一步：画调用树 → 看结构 → 再手算
Step 1 of every recursion problem: draw the call tree

fact(5) 的调用树

fact(5) ──> 5 × fact(4)
              │
              └─> fact(4) ──> 4 × fact(3)
                                │
                                └─> fact(3) ──> 3 × fact(2)
                                                  │
                                                  └─> fact(2) ──> 2 × fact(1)
                                                                    │
                                                                    └─> fact(1) = 1  ← 终止
🔍 树的 3 个特征
  • 根：最上层的 fact(5)
  • 叶：最底层的 fact(1) = 1
  • 分支：每次调用产生一个子节点
❓ fact(5) 调用了多少次 fact 函数？（包括 fact(5) 本身）
看答案
5 次：fact(5) → fact(4) → fact(3) → fact(2) → fact(1)
ACSL Wiki · Sample 1

真题风格 · 单变量 1 分支
Single-variable, 1 branch

题目出自 ACSL Wiki · 真实风格

Sample 1 题干

g(x) = {
   g(x-3) + 1    if x > 0     ← 分支 1（递归）
   3x              otherwise    ← 分支 2（base case）
}

求 g(11) = ?

调用树

g(11)
 └─> g(8) + 1        (x=11>0)
      └─> g(5) + 1    (x=8>0)
           └─> g(2) + 1    (x=5>0)
                └─> g(-1) + 1    (x=2>0)
                     └─> 3 × (-1) = -3    ← base case

向上回填

g(-1) = -3
g(2)  = -3 + 1 = -2
g(5)  = -2 + 1 = -1
g(8)  = -1 + 1 = 0
g(11) = 0 + 1 = 1   ← 答案
ACSL Wiki · Sample 2

真题风格 · 多分支含 x<0 反弹
Multi-branch with x<0 bounce

陷阱题：x<0 不是"无解"，而是"反弹分支"

Sample 2 题干

h(x) = {
   h(x-7) + 1    if x > 5      ← top 规则
   x              if 0 ≤ x ≤ 5   ← middle 规则（base）
   h(x+3)         if x < 0      ← bottom 规则（反弹！）
}

求 h(13) = ?

调用树 + 手算

h(13)              (x=13>5)
 └─> h(6) + 1           (x=6>5)
      └─> h(-1) + 1        (x=-1<0, 反弹！x+3=2)
           └─> h(2)            (x=2, 0≤x≤5, base)
                └─> 2             ← base 命中

向上回填：
h(-1) = 2
h(6)  = 2 + 1 = 3
h(13) = 3 + 1 = 4   ← 答案
⚠️ 关键陷阱

看到 x<0 不要放弃！这是反弹分支，参数会变大但最终仍会落到 base case。

ACSL Wiki · Sample 3

真题风格 · 双变量
Two variables (x, y)

两个变量同时变化 · 要追踪 (x, y) 两个值

Sample 3 题干

f(x, y) = {
   f(x-y, y-1) + 2    if x > y    ← 两个变量都变
   x + y              otherwise    ← base case
}

求 f(12, 6) = ?

调用树（追踪 x 和 y）

f(12, 6)              (12>6)
 └─> f(6, 5) + 2           (6>5)
      └─> f(1, 4) + 2           (1≤4, base!)
           └─> 1 + 4 = 5          ← base 命中

向上回填：
f(6, 5)  = 5 + 2 = 7
f(12, 6) = 7 + 2 = 9    ← 答案
🎯 追踪技巧

在纸上一边写 (x, y) 两个值：(12,6) → (6,5) → (1,4)，每次变换都标出来。

Sample 4 题干

一个 16 英尺的正方形，按以下算法迭代涂色：

  • 第 1 次：涂中间 1×1 英尺的小方块
  • 第 2 次：在剩余部分涂中间 1/9 区域
  • 第 3 次：再次在剩余涂 1/9...

问：最终涂了多少平方英尺？

手算过程

总面积 = 16×16 = 256
第 1 次：涂 1×1 = 1，剩余 256 - 1 = 255
第 2 次：涂 255 ÷ 9 = 28.33，剩余 226.67
第 3 次：涂 226.67 ÷ 9 ≈ 25.19...
...
几何级数求和：
总涂色 = 1 + 28.33 + 25.19 + ... ≈ 175 平方英尺

⚠️ 此题 ACSL Junior 不考，仅 Senior 出现

4 道题 · 完整手算过程

每道题都画调用树 · 验证你的理解

题 1 · h(7) = 6

h(7)              (7>3)
 └─> h(5) + 1           (5>3)
      └─> h(3) + 1           (3, 0≤3≤3, base)
           └─> 3

h(5) = 3 + 1 = 4
h(7) = 4 + 1 = 5

等等！让我重做...
h(7): x=7>3, 走 h(x-2)+1 = h(5)+1
h(5): x=5>3, 走 h(x-2)+1 = h(3)+1
h(3): x=3, 0≤3≤3, base = 3

回填：
h(3) = 3
h(5) = 3+1 = 4
h(7) = 4+1 = 5

题 2 · hanoi(4) = 15

hanoi(1) = 1
hanoi(2) = 2×1 + 1 = 3
hanoi(3) = 2×3 + 1 = 7
hanoi(4) = 2×7 + 1 = 15

调用树：
hanoi(4) = 2×hanoi(3)+1
          = 2×(2×hanoi(2)+1)+1
          = 2×(2×(2×1+1)+1)+1
          = 2×(2×3+1)+1
          = 2×7+1 = 15

题 3 · f(10, 3) = 5

追踪 (x, y)：
f(10, 3)              (10>3)
 └─> f(7, 4) + 1           (7>3)
      └─> f(3, 5) + 1           (3≤5, base!)
           └─> 3 - 5 = -2

回填：
f(7, 4)  = -2 + 1 = -1
f(10, 3) = -1 + 1 = 0

(陷阱：y 也在变！(3→4→5)，最后 x≤y)

题 4 · f(9) = 13

f(9)               (9>5)
 └─> f(8) + 2           (8>5)
      └─> f(7) + 2           (7>5)
           └─> f(6) + 2           (6>5)
                └─> f(3) + 2           (3, 2<3≤5)
                     └─> f(0) + 2           (0≤2, base)
                          └─> 3×0 = 0

回填：
f(0) = 0
f(3) = 0 + 2 = 2
f(6) = 2 + 2 = 4
f(7) = 4 + 2 = 6
f(8) = 6 + 2 = 8
f(9) = 8 + 2 = 10
⚠️ 5 Common Pitfalls

递归5 大陷阱
5 traps to avoid

这些都是学生常犯的错误 · 看一遍避坑

① 忘 base case

def f(n): return f(n+1)  # 💥 死循环

② base case 写错

f(0)=1, f(1)=0  # 💥 永远进不去

③ 多分支判断错

x=5 时选了 x>5 而不是 x≤5
→ 仔细读 if 条件

④ x<0 被忽略

当无解放弃
→ 这是反弹分支，别放弃！

⑤ 双变量只看一个

追踪 f(x,y) 漏掉 y 的变化
→ 同时追踪 (x, y)

每道题都画调用树
手算时不跳步
