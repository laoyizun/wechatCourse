# ACSL 备赛 · 术语中英对照表

> ACSL 笔试和编程题的**语言是英文**。中国阿思丹赛区虽然说"中英文"，但**实际题目以英文为主**。学生必须熟悉术语英文，否则看不懂题目。
>
> 使用方法：每个术语在 PPT 中首次出现时用 `.en-tag` 类标注（蓝色 chip），考试高频词单独列出。

## ACSL 题目常见开头句式

```
1. Convert [number] in base [X] to base [Y].
2. What is the decimal value of [binary string]?
3. Compute [binary add expression].
4. What is f(n) if f is defined recursively as...?
5. Convert the infix expression [...] to postfix.
6. Flick the bits in the string [...] using [...].
7. Simplify the Boolean expression [...] using De Morgan's Law.
8. Build the truth table for [...]
9. Insert [...] into the BST. Show the result.
10. How many vertices/edges does the graph have?
11. What is the truth table for the circuit [...]?
```
