变量

Python 变量定义、命名规则与值的修改

📋 变量定义 Definition
  • 语法：变量名 = 值
  • 变量名：标识符，用于引用变量。
  • 等号 =：赋值符号，把右边的值赋给左边的变量。
  • 值：变量存储的具体内容。
# 基本写法
name = value

# 示例
score = 0
player_name = "Alice"
is_ready = True
🌳 命名规则 Naming Rules
  • 组成字符：只能包含字母、数字和下划线。
  • 首字符：不能以数字开头。
  • 大小写：区分大小写，life 和 Life 是不同变量。
  • 关键字：不能使用 Python 保留字（如 if、for、class）。
  • 推荐风格：小写字母 + 下划线分隔多个单词（PEP 8）。
# 合法
score = 100
star_speed = 50
_private = "secret"
name1 = "Bob"

# 非法
1score = 100         # 数字开头
star-speed = 50      # 连字符
if = 10              # 关键字
my name = "Alice"    # 空格
⚙️ 值的修改 Reassignment
  • 重新赋值：对同一变量再次使用 =，新值覆盖旧值。
score = 0
print(score)          # 0

score = 100
print(score)          # 100

score = 50
print(score)          # 50
➕ 增加与减少 Increment / Decrement
  • 复合赋值：x += n 等价于 x = x + n。
  • 减法赋值：x -= n 等价于 x = x - n。
score = 0

score = score + 10    # 加法：score = 10
score += 20           # 等价写法：score = 30
score -= 5            # 减法：score = 25

life = 5
damage = 1
life -= damage        # life = 4

Python 没有 ++ 和 -- 运算符。

📌 老师注记
  • = 是赋值：Python 中 = 用于赋值；判断相等用 ==。
  • 无 ++ / --：Python 不支持 x++，必须用 x += 1。
  • 关键字：if、for、while、class 等保留字不能作为变量名。
  • 易混字符：变量名 l（小写 L）与数字 1、O 与 0 视觉上接近，建议避开。
