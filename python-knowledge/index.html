❓ 常见问题 FAQ

  • Python 是什么？
    一门适合入门的编程语言，可用于游戏开发（MakeCode Arcade）、网站、数据分析、人工智能等。本课程面向 3-6 年级小学生。
  • Python 和 MakeCode Arcade 的 Python 一样吗？
    MakeCode Arcade 使用的是 "Static Typed Python"，语法上接近 JavaScript（用 function 而非 def）。本手册讲的是标准 Python 语法，核心概念通用。
