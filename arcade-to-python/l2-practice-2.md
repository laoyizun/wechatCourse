过年啦！奶奶给了小明一个红包，里面有 100 元。

奶奶说："拿去跟 4 个小朋友分一分。"

~hint
这是 L2 的第二个填空练习——红包分配。

100 元分给 4 个小朋友，要算两个数：

1. 每人分到多少？
2. 还剩多少？

这两个问题用 Python 的两个新运算符：

- // 是整数除法（向下取整）：100 // 4 = 25
- % 是模数（取余数）：100 % 4 = 0

加起来：25 × 4 + 0 = 100，没错！
hint~

## {3. 问题在哪 @showdialog}

100 ÷ 4 = 25，每人 25 元，刚好分完，没剩钱。

~hint
两个新运算符：

- // 是"整数除法"——结果向下取整。100 // 4 = 25，99 // 4 = 24（不是 24.75）
- % 是"模数"——取余数。100 % 4 = 0，99 % 4 = 3

经典组合：

- // 用于"分多少份"
- % 用于"剩多少"

合起来验证：each * people + leftover = total_money
hint~
