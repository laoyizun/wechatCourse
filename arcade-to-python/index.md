# arcade->python

本课程是为**从图形化编程迁移到文本编程**的小学生设计的 Python 入门课。

通过 8 节课，学生将掌握 Python 的 4 个核心概念：**变量、运算符、if/else、循环**，并在"星际冒险"游戏项目中不断应用所学知识。

每节课约 90 分钟，按 3 段式教学：
- **前段**：知识引入（约 25-30 分钟）
- **中段**：3-5 个独立小练习（约 30-40 分钟）
- **后段**：长项目学以致用（约 20-30 分钟）

## 学习目标

完成本课程后，学生应能：
- 理解 Python 变量、运算符、if/else、循环 4 个核心概念
- 在 MakeCode 环境中独立编写 50-100 行的 Python 程序
- 把编程知识应用到"星际冒险"游戏项目中
- 从图形化编程顺利迁移到文本编程
